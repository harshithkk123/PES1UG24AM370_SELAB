# Issues found in `theater_system.py`

Line numbers refer to the **original** file. Issues are ordered by severity (high and medium first). Three of them (marked "found by running") are not reported by any of the three tools.

| Issue | Type | Line(s) | Description | Fix Approach |
|-------|------|---------|-------------|--------------|
| World-writable file permissions | Security, High (Bandit B103) | 55 | `os.chmod("seats.json", 0o777)` lets every user on the machine read, modify and execute the bookings file, so anyone could tamper with reservations. | Removed `0o777`. `dump_reservations()` now sets `0o600` (owner read/write only) right after writing the file. |
| Weak MD5 hash for ticket codes | Security, High (Bandit B324, reported as B303 in older versions) | 25 | MD5 is a broken hash. The input `show_id + str(seat_number)` is also ambiguous: `"SHOW-1" + "15"` and `"SHOW-11" + "5"` both give `"SHOW-115"`, so two different seats can get the same code. | Switched to SHA-256 and hash `f"{show_id}:{seat_number}"` with a separator. (If codes must be unforgeable, an HMAC with a secret key would be the next step.) |
| Seat numbers never validated | Bug, Medium (found by running) | 9-16, 45-47 | Seat 25 is accepted for a 20-seat show, and `-1` and `"A7"` are accepted too. Invalid seats use up capacity: SHOW-2 reported 7 seats free when only 1 valid seat was booked. An unknown `show_id` crashes with `KeyError`. | Added `_is_valid_seat()` (whole number from 1 to the show's capacity). `reserve_seat()` uses `shows.get()`, rejects unknown shows and invalid seats, and logs the reason. |
| Typed seat stays a string | Bug, Medium (found by running) | 50-51 | `input()` returns text, so the default seat is the string `"4"`, not the number `4`. `"4"` and `4` count as different seats, so one seat can be booked twice. Text like `"abc"` was accepted as a seat and `seats.json` mixed types. | Added `parse_seat()` which converts with `int()`. Non-numeric input is rejected and logged. |
| Mutable default argument | Bug, Medium (Pylint W0102) | 9 | `system_logs=[]` is created once and shared by every call, so log entries from unrelated calls pile up (and nothing ever reads them). | Default is now `None` and a fresh list is created inside the function. `main()` passes its own `logs` list and prints it at the end. |
| Bare `except` that swallows every error | Bug, Medium (Pylint W0702, Flake8 E722, Bandit B110 Low) | 19-22 | `except: pass` hides all errors, including the `KeyError` for an unknown show and the `ValueError` when the seat is not booked. `release_seat("SHOW-2", 3)` silently did nothing. | Removed the `try/except`. The show and seat are checked explicitly and the function returns `True` or `False`. |
| Files opened without `with` and without encoding | Resource handling, Medium (Pylint R1732, W1514) | 28-29, 33-34 | The file handles are never closed, so the saved data only reaches disk when the garbage collector closes the file before it is read back. No encoding is given, so behaviour depends on the OS locale. | Use `with open(path, ..., encoding="utf-8")` together with `json.dump()` and `json.load()`. |
| `global` statement | Design, Low (Pylint W0603) | 32 | `load_reservations()` rebinds the module-level `shows` through `global`, a hidden side effect that is hard to follow. | Update the existing dictionary in place with `shows.clear()` and `shows.update(data)`. |
| `main()` runs on import | Design, Low (found by running) | 57 | Importing the module runs the whole demo, asks for input and writes `seats.json`, so the functions cannot be reused or tested. | Wrapped the call in `if __name__ == "__main__":`. |
| Missing docstrings | Documentation, Low (Pylint C0114, C0116) | 1, 9, 18, 24, 27, 31, 37, 42 | The module and all seven functions have no docstring. | Added a module docstring and a one-line docstring for every function. |
| Invalid names | Style, Low (Pylint C0103) | 28, 33, 37, 38 | `printSeatingSummary` is camelCase, and `f` and `s` are too short to say what they hold. | Renamed to `print_seating_summary`, `seats_file` and `show`. |
| `%` string formatting | Style, Low (Pylint C0209) | 12, 15 | Old-style `%` formatting instead of f-strings. | Replaced with f-strings. |
| Looping over keys, then indexing | Style, Low (Pylint C0206) | 38-40 | `for s in shows` followed by `shows[s]` three times. | Loop with `for show in shows.values()`. |
| Missing blank lines | Style, Low (Flake8 E302 x7, E305) | 9, 18, 24, 27, 31, 37, 42; 57 | PEP 8 requires two blank lines around top-level functions. | Added the missing blank lines. |
| Lines too long | Style, Low (Flake8 E501, Pylint C0301) | 12 (83 chars), 40 (104 chars) | Both lines exceed 79 characters, and line 40 is also over Pylint's limit of 100. | Wrapped the lines. |
